Makineler

Canli durum

Canli sinyal ve esik durumu. Dongu sayimi degil; sadece «reflektor cizgide gorunuyor mu?» teshisi.

Tespit esigi (prom≥…): reflektör icin gereken minimum Δ. Canli Δ bu esikten buyuk veya esit olmali; yani esik, olculen Δ'dan kucuk olmali — yoksa reflektör «bulunamadi» kalir.
Offset (off ±…): tespit esigine eklenir/cikarilir. Aktif esik ≈ prominens esigi + offset. Negatif offset = daha hassas bulma; pozitif = daha sert.
peak/bg: takip cizgisi + kalinlik bandinda olculur. peak = en parlak nokta (0–255), bg = arka plan parlakligi. Δ = peak − bg. Reflektör parlakligi / zemin farki degistikce (isik, kir, aci) peak/bg degisir; esikle karsilastirilip nokta kabul edilir. len = parlak segment uzunlugu.

Makine parametreleri

Makine bu kameranin goruntusu uzerinden calisir.

Cizgi boyunun kesri (0-1).

Detay grafikte bu sure boyunca dongu yoksa cizgi kopar + kirmizi durus. Sayima etki yok.

Canli sayim: zigzag peak/trough (global min_prominence=0.12, jump_abs=0.30). Asagidaki «Sayim modu / Schmitt» alanlari kaydedilebilir ama canli sayimda kullanilmaz. Ustteki threshold / peak-bg / uzunluk alanlari reflektor tespit icindir (parlak nokta bulma); dongu sayaci degildir.

Yetkilendirme

Kurulum adimlari
  1. Telegram'da @BotFather acin → /newbot yazin.
  2. Bot adi verin (ornek: Fabrika Kalip).
  3. Kullanici adi xxxxxx_bot formatinda olmali (ornek: alfamold_bot).
  4. BotFather'in verdigi token'i asagiya yapistirin → Bot Ayarlarini Kaydet.
  5. Telegram aramada bot kullanici adinizi yazin (ornek @alfamold_bot) veya t.me/alfamold_bot acin.
  6. Bota /start basin (bir kez yeterli).
  7. Operatör Telegram ID ogrenmek icin: @userinfobot acin → Start → Id: 123456789 satirini okuyun.
  8. Operatör eklerken Seviye 1 (atama+üretim) veya Seviye 2 (sadece atama) seçin.
  9. QR formatlari: makine MACHINE:3 · kalip MOLD:042
